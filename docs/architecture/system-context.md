# System Context

- Status: In Review
- Owner: Keith / Codex

## 目的

サービスの外部システム、利用者、主要境界を整理する。

## 背景

人事システム、認証基盤、CSV、BI ツールなど外部連携の可能性が高く、境界の定義が重要。

## 前提

- SaaS として提供する想定
- 複数企業の利用を前提とする可能性が高い
- MVP と第 2 フェーズでは、単一アプリケーション構成を優先する

## 決定事項

- MVP と第 2 フェーズは、`モジュラモノリス` による単一アプリケーション構成を第一候補とする
- 外部境界は、利用者, 認証基盤候補, CSV 入出力, ファイル保存先を中心に整理する
- 専用検索基盤, 分析基盤, AI 要約基盤は初期境界に含めない
- 初期の認証方式は `アプリ内認証で開始し、後で SSO を追加する方式` を第一候補とする
- `MVP` はアプリ内認証のみを第一候補とし、`第 2 フェーズ` でも SSO は必須にしない
- SSO は、顧客要件または導入運用上の必要性が明確になった時点で `第 3 フェーズ以降` の追加候補とする

### 現時点の主要アクター

- `HR_ADMIN`
- `MANAGER`
- `ORG_ADMIN`
- `EXECUTIVE_VIEWER`
- `EMPLOYEE`

### 現時点の主要外部境界

- 認証基盤
  - MVP はアプリ内認証を第一候補とし、将来の外部 IdP 連携を追加候補とする
- ファイル保存先
  - 初期はローカルファイル保存を第一候補とする
  - 将来は別サーバや `S3` 互換ストレージへ差し替え可能な形を目指す
- 管理者作業用入出力
  - CSV 取込, CSV 出力

### 初期境界に含めないもの

- 専用検索エンジン
- 分析用 DWH
- AI 要約や推薦の外部処理基盤
- メール送信基盤

## 検討した選択肢

- 単一アプリケーションで始める
- 最初から明確なサービス分割を行う
